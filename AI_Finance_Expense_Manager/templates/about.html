Receipt generation

Create a receipt and print it or save it as a PDF.

Technology stack

PythonFlaskSQLiteHTML5CSS3JavaScriptChart.js

How the project works

  1. User enters income and expense transactions.
  2. Flask stores records in a local SQLite database.
  3. Python calculates totals and a simple expense estimate.
  4. Chart.js displays spending and cash-flow charts.
  5. The receipt page formats payment details for printing or PDF saving.
Academic note: This is a demonstration project, not a bank-connected financial service. It does not access bank accounts or provide professional financial advice. The forecasting feature is a simple statistical estimate, not a trained AI model.
